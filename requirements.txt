# requirements.txt is found first, so THIS file installs streamlit/plotly/

# also runs `pip install .` because pyproject.toml has a [build-system] table —
# that is a DIFFERENT mechanism (it registers this repo as an importable
# package so `import stock_scanner...` resolves), not a competing requirements
# source. Its [project.dependencies] (pandas/numpy/pyarrow/loguru/pyyaml/
# requests) is a deliberate subset of what's below — kept version-identical to
# this file's equivalent lines (enforced by tests/test_dependency_consistency.py)
# so the two independent install steps can never disagree.
# ─────────────────────────────────────────────────────────────────────────────

# Dashboard
# PIN streamlit: the unpinned ">=1.35,<2.0" let Streamlit Cloud install the
# latest 1.x (e.g. 1.58), which (a) changes native-widget DOM/CSS so theme
# overrides can miss, and (b) breaks this app's selectbox session_state usage
# (KeyError on widget keys). 1.37.1 is the version the dashboard is built and
# contrast-verified against, so pin it for a deterministic, working deploy.
#
# DEPLOY PYTHON VERSION — IMPORTANT: use Python 3.12 (or 3.11/3.13) on Streamlit
# Community Cloud. streamlit 1.37.1 requires `pillow<11`, and the newest such

# deploy runs on Python 3.14 (Cloud's current forced default), pip can't find a
# Pillow wheel and tries to build it from source -> "Failed building wheel for
# pillow". On Python 3.12 every dependency installs from a wheel. Set the Python
# version in the app's deploy "Advanced settings" (see runtime.txt / .python-version).
